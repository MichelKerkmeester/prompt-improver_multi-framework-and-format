# v1.2.0.0, Layout Matches the sk-doc Convention

Prompt Improver's on-disk layout now follows the sk-doc packaging convention. The skill folder, hyphenated skill filenames, the README, SYNC.md and two new advisor files carry that shape. The version pin moves from 1.1.2 to 1.2.0 across SKILL.md, `claude project/Custom Instructions.md` and every paired knowledge mirror, while CLEAR scoring and framework selection stay untouched.

## Why This Release

The sk-doc packaging convention is already rolling out across the rest of the Barter AI systems fleet. This release brings Prompt Improver's on-disk layout in line with it. The same rename-and-hyphenate pattern lands in Copywriter, Deal Templates, Blog Posts, both LinkedIn systems, both Sales systems and Media Editor. A closing audit catches and fixes leftover drift between the mirrored surfaces.

## What's New at a Glance

- **The skill folder renames from `skill/` to `sk-prompt-improver/`.** Cross-references in SKILL.md, AGENTS.md and the reference files update to the new hyphenated paths. Only the paired source paths on the versioned `claude project/knowledge/` mirrors change, while those mirror filenames stay display-named rather than hyphenated.
- **All 13 underscored filenames convert to hyphenated form.** The 6 references are `depth-framework.md`, `interactive-mode.md`, `patterns-evaluation.md`, `visual-mode.md`, `image-mode.md` and `video-mode.md`. The 7 assets are `framework-pattern-library.md`, `format-guide-markdown.md`, `format-guide-json.md`, `format-guide-yaml.md`, `visual-mode-library.md`, `image-mode-library.md` and `video-mode-library.md`.
- **SKILL.md follows the create-skill standard.** It keeps its section shape and folds the standalone "REFERENCES AND RELATED RESOURCES" section into a "Dynamic Discovery" subsection under section 5 REFERENCES, taking the file from eight top-level sections to seven. The frontmatter version moves from 1.1.2 to 1.2.0.
- **The routing example drops what `route_prompt_improver_resources` never called.** The dictionaries `MODE_CONFIDENCE`, `PRELOAD_GROUPS`, `MODE_PATTERNS`, `UI_PLATFORM_PATTERNS`, `IMAGE_PATTERNS`, `VIDEO_PATTERNS` and `FRAMEWORKS` go, along with the unused `HIGH`, `MEDIUM` and `FALLBACK` confidence tiers and the helpers `detect_mode`, `detect_framework` and `detect_complexity`.
- **The root README is a symlink to the skill README.** The old root file, headed "Prompt Engineering Assistant - User Guide v0.200", is preserved verbatim as `z_legacy/Prompt - Root README (superseded) - v0.980.md`. A new descriptive skill README lives at `sk-prompt-improver/README.md` and the root `README.md` is a symlink to it, so anything reading the root file still lands on current content with no second copy left to drift out of sync.
- **SYNC.md is numbered to the sk-doc standard.** It grows from a five-section informal manifest into an eight-section document. The sections are OVERVIEW, WHEN TO SYNC, MANUAL-LOAD CONTRACT, SOURCE-TO-MIRROR INVENTORY, SYNC WORKFLOW, REQUIRED PARITY, DRIFT CHECKS and RELATED DOCUMENTS.
- **REQUIRED PARITY states what both packagings must agree on.** It spells out, for the first time in this file, the exact ten routed intents, command aliases, DEPTH energy and phase pairings and scoring floors. DRIFT CHECKS closes with a runnable manual check sequence in place of the old prose description.
- **Two advisor metadata files ship for the first time.** `description.json` carries the skill id, a 24-entry keyword list and ten trigger examples for advisor routing. `graph-metadata.json` is a schema-versioned sibling-edge map that names `sk-prompt` at weight 0.4 as the prompt-craft peer and `sk-doc` at weight 0.2 as the documentation-packaging peer.
- **AGENTS.md lists the three mode-library assets.** The resource dependency diagram was missing `visual-mode-library.md`, `image-mode-library.md` and `video-mode-library.md`. It now includes those entries.
- **Custom Instructions uses the skill's creative-follow-up rule.** `claude project/Custom Instructions.md` carried an orphaned "Human Voice Rules pass across all modes" line with no counterpart anywhere in SKILL.md. The closing audit replaces it with SKILL.md's own long-standing creative-follow-up rule inviting the user to share the generated result for one more refinement pass.

## Upgrade

Use `sk-prompt-improver/` in place of `skill/` and the hyphenated filenames in place of the underscored ones. The root `README.md` is a symlink to `sk-prompt-improver/README.md`, so that path still opens the current guide. The retired root guide remains at `z_legacy/Prompt - Root README (superseded) - v0.980.md`.
