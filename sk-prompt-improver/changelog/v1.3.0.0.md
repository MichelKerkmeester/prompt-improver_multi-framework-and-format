## [**1.3.0.0**] - 2026-08-06

Smart-routing hardening release. Section 2 now carries the canonical five routing subsections in order (Primary Detection Signal, Phase Detection, Resource Domains, Resource Loading Levels, Smart Router Pseudocode), an executable route oracle lands at `benchmark/router/`, `Custom Instructions.md` becomes the sole Project routing authority, and the `SKILL.md` mirror is removed from Project Knowledge. `sk-prompt-improver/SKILL.md` moves 1.2.1 to 1.3.0, `claude project/Custom Instructions.md` moves 1.2.1 to 1.3.0.

> Scope: routing-contract hardening and oracle, Project-package mirror removal, kernel rebuild. No mode, command, keyword or scoring-gate behavior changes; the ten routed intents, their aliases and their gates are unchanged.

---

### Command Detection Hardened To Exact Tokens

`SKILL.md`'s command and keyword tables were previously one combined `INTENT_MODEL` scored by a single substring `in` check, so a `$` command like `$short` and a natural-language word like `concise` were indistinguishable failure surfaces: a command embedded inside a longer token, or a keyword embedded inside an unrelated word, could both silently score. The router now tokenizes every `$` command with a whole-token regex and checks set membership, and scores every remaining natural-language keyword on a word boundary. Neither can fire as a substring inside a longer word.

&nbsp;

### Command Wins, Conflicts Ask

A single explicit mode command now selects its intent outright over any natural-language score, so `$short but this is a deep, complex, multi-step system` binds Short, not Deep, even though Deep's keywords score far higher unweighted. Two conflicting mode commands in the same request no longer resolve to an arbitrary winner: they route to Interactive Mode, matching the Skill's own pre-existing "multiple commands conflict" escalation rule, now actually enforced by the router instead of only described in prose.

&nbsp;

### Format Lock Separated From Mode

The prior `FORMAT` key competed inside the same intent-scoring race as the nine process modes, so a bare `$json` could in principle steal the primary route away from a co-occurring mode signal. Format detection is now its own axis, matching the Skill's own "detect format modifiers independently from mode" routing-workflow line: `$json`, `$yaml` and `$markdown` (`$j`/`$y`/`$md`/`$m`) lock the output format on their own axis and never compete with the mode intent for the primary route. A bare format command with no mode signal still asks about the mode while the format stays locked and its format guide still loads.

&nbsp;

### Executable Route Oracle

New `benchmark/router/route_contract.py`, `fixtures.json` (25), `run_fixtures.sh` and `README.md`, structured on the Media Editor canary. The route object is `{intent, energy, scorer, format, source, needs_disambiguation, resources}` over the fourteen intents (Raw, Text, Improve, Refine, Short, Deep, Visual, MagicPath, Image, Video, Framework, Scoring, Interactive, Thinking), with runtime discovery against the live `references/*.md` and `assets/*.md` inventory, guarded loading, and a fixed-field schema validator that rejects unknown or duplicate fields and invalid enum values. Fixtures cover every `$` command, several natural-language routes, a command-precedence case (`$short` beats co-occurring Deep keywords) and a word-boundary case (`ask` inside `basket` does not fire Interactive).

&nbsp;

### Custom Instructions Rebuilt As The Project Routing Authority

`claude project/Custom Instructions.md` is rebuilt as a faithful, Project-adapted mirror of the hardened Skill: the same routing description (advisory-phrased, since a Project cannot execute the tokenizer), the full ALWAYS/NEVER/ESCALATE rule set restructured to match `SKILL.md`'s own Section 4 headers, the DEPTH energy table, Operating Modes, Framework Library, Scoring Summary, Fallback Chains, Quality Gate, Delivery Protocol and Quality Checklist. It states plainly that it is the routing authority for this Project because `SKILL.md` is not loaded here.

&nbsp;
