## [**1.5.2.0**] - 2026-09-27

Header divider release. Every delivered file and every Deliverable Block now keeps its `Mode:` header apart from the prompt with a blank line, `---` and a blank line, so a reader copying the prompt never takes the header with it. `sk-prompt-improver/SKILL.md` moves 1.5.1 to 1.5.2 and the kernel moves v1.6.0 to v1.6.1.

> Scope: the file layout in `SKILL.md`, the three format guides and their Project twins, the kernel's rule 7 and DELIVERY PROTOCOL template, the playbook, `benchmark/grader/deliverable_lint.py` and the 66 exports in `export/benchmark/`. No header field, rubric, routing, command, framework, scoring-gate or question-flow behavior changes.

---

### A Divider Under The Header

The header line sat directly on top of the prompt, after one blank line or none. `SKILL.md` Format Selection, rule 23 and Output File Rules now name the divider, and the Output File Rules line spells the layout out: the header, a blank line, `---`, a blank line, then the prompt. Each format guide shows the divider in its Mandatory Header Format block and in every example, lists it in the allowed-content table and checks it in its checklists. The JSON and YAML guides add that the payload below the divider must parse on its own.

The kernel's rule 7 names the divider and its DELIVERY PROTOCOL template shows it, so a Project block now carries two `---` lines: one under the header and one above the attestation. The format lock covers only the prompt between the two. The three residency-declared statements that carry this text were resynced with `resync_statement.py`.

&nbsp;

### Checks And Scenarios

`deliverable_lint.py` reports `header_divider_missing` when the first non-blank line after the header is not `---`, or when no blank line sits between the two, since Markdown would then read the header as a heading. The playbook root lists a missing divider as an advisory defect, and the six format-lock scenarios, which exist to test delivery shape, fail on it. The other scenarios describe the layout and parse the payload below the header and its divider. Line citations into the changed guides and the kernel moved with them.

&nbsp;

### Benchmark Exports

The 66 files in `export/benchmark/skill/` and `export/benchmark/claude project/` took the divider through a one-off script, not a rerun, with no other byte changed. The 2026-09-25 and 2026-09-27 run READMEs record the edit, and each run's collector now keeps the edited files with a warning.
