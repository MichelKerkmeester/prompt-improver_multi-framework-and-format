# v1.2.1.0, Kernel and Sources Match the Skill

This correction and alignment release closes fourteen of the fifteen confirmed gaps in the Custom Instructions kernel, the source and the README against the authoritative Skill. The Custom Instructions kernel moves from 1.2.0 to 1.2.1. `SKILL.md` moves from 1.2.0 to 1.2.1 for the new Claude Projects delivery override. Patterns and Evaluation, Visual Mode, Image Mode and Video Mode are updated for a package-relative link fix. Both non-Markdown format guides are updated for that same delivery override.

One further finding does not land. Adding RAG frontmatter fields to `SKILL.md` is carried as an amendment candidate rather than applied, because the fleet-wide convention across all ten systems keeps that frontmatter to name, description, allowed-tools and version.

## Why This Release

Fifteen confirmed gaps in the kernel, the source and the README were found against the authoritative Skill. This release applies fourteen of them. The remaining finding, adding RAG frontmatter fields to `SKILL.md`, is escalated rather than forced.

## What's New at a Glance

- **Explicit `$` commands override natural language.** Explicit `$` commands override conflicting natural-language signals, and a clarifying question is required when multiple commands conflict, matching the Skill's router authority and its command-conflict escalation rule.
- **Raw opens only through `$raw`.** The Raw path drops the natural-language bypass triggers "clean this" and "no scoring".
- **Deep selects a framework by complexity.** The Deep path no longer names a fixed TIDD-EC/CRAFT default. It reads complexity-matched framework selection, consistent with the Skill's own Deep mapping and the kernel's lightest-fitting-framework rule.
- **MagicPath sub-gates join the EVOKE threshold.** The rule gains the MagicPath Kinetic (8+/13), Visual (8+/12) and combined Kinetic+Visual (18+/25) sub-gates alongside the existing 42+/50 total.
- **The Deliverable Block header gains Complexity.** The Complexity field matches the Markdown format guide's own header contract. The Block-contents rule names complexity alongside mode, framework, score and attestation.
- **The format lock covers only the enhanced prompt.** The header and the attestation are delivery metadata that frame the payload and sit outside the JSON/YAML format lock.
- **JSON and YAML deliverables state their token overhead.** The post-block chat contract and its matching rule gain a token-overhead line for those deliverables.
- **Claude Projects delivers through the Deliverable Block.** `SKILL.md` and both non-Markdown format guides state that claude.ai Projects cannot write files and that the Deliverable Block substitutes for the saved file. The guides add this as a third Delivery Methods entry next to Claude Desktop/IDE and CLI/Agent Mode, and the CLI runtime keeps its export-first requirement.
- **Reference files replace package-relative asset links with plain text.** Patterns and Evaluation, Visual Mode, Image Mode and Video Mode drop every `../assets/...` link and convert each one to a plain-text asset mention. `claude project/` has no `references/` or `assets/` subdirectory, so the old links never resolved there.
- **The README and `SYNC.md` catch up with the sources.** Set Up names the full ten-intent-plus-Interactive routing matrix, false-command handling, MagicPath-over-Visual precedence and format-lock independence in place of a flat per-mode list and exempts Raw from the routed-score confirmation. The Change Checklist requires a mirror rename and removal of the superseded filename on every version bump, with Known Notes naming the four largest mirrors by byte count and with `SYNC.md` matching the new filenames and versions.
- **Corrected files move to new version numbers.** Custom Instructions and `SKILL.md` move from v1.2.0 to v1.2.1, the JSON and YAML format guides from v0.141 to v0.142, Patterns and Evaluation from v0.211 to v0.212, Visual Mode from v0.300 to v0.301 and Image Mode and Video Mode from v0.122 to v0.123.
- **RAG frontmatter is not added to `SKILL.md`.** That finding stays an amendment candidate rather than applied. Frontmatter across all ten systems stays name, description, allowed-tools and version.

## Command Precedence

#### Explicit Commands Override Natural Language

The kernel now states that explicit `$` commands override conflicting natural-language signals. A clarifying question is required when multiple commands conflict. This matches the Skill's router authority and its command-conflict escalation rule.

&nbsp;

#### Raw Opens Only Through $raw

The Raw path entry in the router diagram drops the natural-language bypass triggers "clean this" and "no scoring". This raw path trigger correction leaves `$raw` as the only way into Raw.

---

## Deep Selection and MagicPath Gates

#### Deep Drops the Fixed Default

The Deep path no longer names a fixed TIDD-EC/CRAFT default. It now reads complexity-matched framework selection. That selection is consistent with the Skill's own Deep mapping and the kernel's lightest-fitting-framework rule.

&nbsp;

#### MagicPath Gains EVOKE Sub-Gates

The EVOKE threshold rule gains the MagicPath Kinetic (8+/13), Visual (8+/12) and combined Kinetic+Visual (18+/25) sub-gates. These sit alongside the existing 42+/50 total.

---

## Deliverable Metadata

#### The Header Names Complexity

The Deliverable Block header gains a Complexity field, matching the Markdown format guide's own header contract. The Block-contents rule now names complexity alongside mode, framework, score and attestation.

&nbsp;

#### Metadata Sits Outside the Lock

A new line defines the header and attestation as delivery metadata that frame the payload. They sit outside the JSON/YAML format lock. The lock applies only to the enhanced prompt content between them.

&nbsp;

#### Chat States the Token Overhead

The post-block chat contract and its matching rule gain a token-overhead line for JSON and YAML deliverables.

---

## Claude Projects Delivery

#### The Block Stands In for the File

`SKILL.md`, `assets/format-guide-json.md` and `assets/format-guide-yaml.md` each gain an explicit Claude Projects delivery branch. `SKILL.md` states plainly that claude.ai Projects cannot write files and that the Deliverable Block substitutes for the saved file. Both format guides add a third Delivery Methods entry that makes the same point next to their existing Claude Desktop/IDE and CLI/Agent Mode entries.

This stops retrieved knowledge from reintroducing CLI-only file-delivery language on the Claude surface. It does not drop any of the CLI runtime's own export-first requirement.

---

## Asset Mentions

#### Plain Text Replaces Package Links

`references/patterns-evaluation.md`, `references/visual-mode.md`, `references/image-mode.md` and `references/video-mode.md` drop every `../assets/...` package-relative link. Each link becomes a plain-text asset mention. `claude project/` has no `references/` or `assets/` subdirectory, so the old links never resolved there.

---

## README and SYNC

#### Set Up Names the Real Router

`claude project/README.md` updates its parity claim, its Set Up smoke-test line, its Change Checklist and its Known Notes. The Set Up section now names the full ten-intent-plus-Interactive routing matrix, false-command handling, MagicPath-over-Visual precedence and format-lock independence in place of a flat per-mode list. It exempts Raw from the routed-score confirmation.

&nbsp;

#### Checklist, Notes and SYNC Catch Up

The Change Checklist gains a step requiring mirror rename and removal of the superseded filename on every version bump. Known Notes gains one advisory line naming the four largest mirrors by byte count. `SYNC.md` updates its source-to-mirror inventory and its version-pin paragraph to match the new filenames and versions.

## File Versions

#### The Corrected Files Take New Versions

`Custom Instructions.md` moves from v1.2.0 to v1.2.1. `sk-prompt-improver/SKILL.md` moves from v1.2.0 to v1.2.1. `assets/format-guide-json.md` and `assets/format-guide-yaml.md` move from v0.141 to v0.142. `references/patterns-evaluation.md` moves from v0.211 to v0.212. `references/visual-mode.md` moves from v0.300 to v0.301. `references/image-mode.md` and `references/video-mode.md` each move from v0.122 to v0.123.

Adding RAG frontmatter fields to `SKILL.md` is escalated rather than forced. It is carried as an amendment candidate rather than applied, because the fleet-wide convention across all ten systems keeps that frontmatter to name, description, allowed-tools and version.
