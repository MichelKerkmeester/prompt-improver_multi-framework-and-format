# v1.0.0.0, The Docs Say What the Router Does

The skill README promised routes the router never takes, and two packaging sentences still described the kernel as it was before the router code moved into it.

## Version Numbering

This is the first stable release. Every earlier release is renumbered as a pre-release: v1.a.b.c became v0.(a+1).b.c, so the previous release, once v1.5.3.0, is now v0.6.3.0. The Project kernel moves to v1.0.0 the same way, and its earlier versions move from v1.a.b to v0.(a+1).b.

## Why This Release

A read-only comparison on 2026-10-01 replayed the README's examples through `benchmark/router/route_contract.py`. "make this UI concept more evocative", "design a fintech dashboard concept" and "this is a complex, multi-stakeholder prompt" reach Interactive or TEXT, not Visual or Deep, "give me this as yaml" locks nothing, and no near-tie rule exists. The root README already stated the real routes.

## What's New at a Glance

- **Routing examples match the router.** The Precedence table writes `$vibe` and `$deep` where the route needs a command, "give me this as yaml" routes to Interactive with Markdown, and the intro example uses "ui design", a real Visual keyword.
- **No near-tie rule.** The highest keyword score wins, and a request no keyword matches falls back to Interactive mode with one comprehensive question.
- **Document-routing bands are advisory.** The skill README no longer says they govern which files load.
- **Packaging sentences follow the router move.** `SKILL.md` no longer says the Project mirrors it, and the skill README says the kernel's Router Code section is this skill's pseudocode with its comments removed, held equal by `benchmark/router/kernel_parity.py`. The system README shows both lines the fixture run prints and lists `kernel_parity.py`.
- **The chat-paste ban is absolute.** `AGENTS.md` dropped "unless explicitly required by a routed mode", because no mode requires one.
- **The kernel stays at v1.0.0.** No kernel line changed, and no routing behavior changed.

No migration required.
