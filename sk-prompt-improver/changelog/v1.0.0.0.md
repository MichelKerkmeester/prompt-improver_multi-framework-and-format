# v1.0.0.0, Two Packagings from One Skill

Prompt Improver adopts the dual-runtime packaging model for the first time. The model ships two packagings of this system. One is the CLI source in `skill/`. The other is the derived claude.ai Project.

Before this release the system shipped as a single versioned knowledge base. Files such as `Prompt - System - Prompt - v0.200.md` and `Prompt - Templates - Visual Mode - v0.200.md` loaded whole, with no router in front of them.

This release introduces `skill/SKILL.md` at version 1.0.0 as a CLI source of truth. It also introduces ten paired files under `skill/references/`, a hand-synthesized `claude project/Custom Instructions.md` plus `claude project/README.md` for the derived claude.ai Project and a new `SYNC.md` manifest. The manifest defines the contract between the two packagings for the first time.

Version records for this system begin here. Full hashes and later renames are tracked in the `v1.1.1.0` and `v1.2.0.0` entries.

## Why This Release

This is the first release that gives Prompt Improver the dual-runtime packaging model. The commit message describes that shared model as "skill + claude-project packaging model." The change lands as part of a same-day rollout across all ten Barter AI systems.

Before this, the knowledge base had no router in front of it and `SYNC.md` did not exist. claude.ai has no filesystem. The new manifest is where the contract between the CLI skill and the claude.ai Project is defined.

## The Skill and the Project

#### The Skill Routes the CLI

`skill/SKILL.md` ships at version 1.0.0. It carries identity, activation triggers, routing and rules that previously lived only in the standalone system prompt. It is the CLI source of truth.

&nbsp;

#### Ten References Have Mirrors

Ten paired reference files land under `skill/references/`. They are `depth_framework.md`, `format_guide_json.md`, `format_guide_markdown.md`, `format_guide_yaml.md`, `image_mode.md`, `interactive_mode.md`, `patterns_evaluation.md`, `system_prompt.md`, `video_mode.md` and `visual_mode.md`. Each pairs with a matching mirror under `claude project/knowledge/`. The mirror uses a descriptive filename, for example `Prompt Improver - DEPTH Thinking Framework - v0.200.md`.

&nbsp;

#### Instructions for the Claude Project

`claude project/Custom Instructions.md` is hand-synthesized. It synthesizes the same rules for claude.ai's no-filesystem environment. `claude project/README.md` ships for the same derived claude.ai Project.

---

## The Sync Contract

#### References Stay Canonical

`SYNC.md` did not exist before this release. The manifest states the sync rule for the first time. `skill/references/` is canonical. Project Knowledge mirrors regenerate by byte-for-byte copy into `claude project/knowledge/` with paired display filenames. A drift-audit shell sequence closes the file. The sequence is a symlink check, a sha256 checksum, a word count and a stale-name grep.

---

## Agents and the README

#### A Wrapper Hands Off Identity

`AGENTS.md` drops the earlier persona-and-boundaries prose. A short enforcement wrapper hands identity straight to `skill/SKILL.md`.

&nbsp;

#### The README Drops Its Markers

`README.md` loses its numbered table of contents and its decorative emoji section markers.

---

## The Archived Knowledge Base

#### Old Files Remain for Comparison

The pre-existing versioned knowledge base is archived under `z_archive/knowledge base/` for manual comparison rather than deleted. That archived knowledge base is ten files. They span `Prompt - Reference - Format Guide JSON - v0.140.md` through the older `v0.121` template files.
