# v0.6.1.0, Prompts Drop the Company Name

The name that two Project deliverables copied in as the user's company is gone from every file a runtime reads. `sk-prompt-improver/SKILL.md` moves 0.6.0 to 0.6.1. The kernel stays at 0.7.0, since no kernel line changed.

## What's New at a Glance

- **The company name in the prompts is gone.** It was "Barter", used as the user's company, where no input names one. In the 2026-09-27 complexity-rubric run, the Project sessions run with no user settings, memory or instruction file.
- **The interactive mode closing line no longer names a company.** All 24 Project sessions in the 2026-09-27 complexity-rubric run read "Interactive framework for Barter prompt enhancement" as the closing line of `Prompt Improver - Interactive Mode - v0.700`, the only Barter text any of them read. `references/interactive-mode.md` and its Project Knowledge twin now read "Interactive framework for prompt enhancement".
- **The two skill reference titles match their Project twins.** `references/depth-framework.md` and `references/interactive-mode.md` no longer start with "Barter -".
- **No rubric or question flow behavior changes.** No rubric, rating scale, band, routing, command, framework, scoring-gate, question-flow or format-lock behavior changes.
- **The skill version moves to 0.6.1.** `sk-prompt-improver/SKILL.md` moves 0.6.0 to 0.6.1. `sk-prompt-improver/description.json` and `sk-prompt-improver/README.md` move 0.6.0.0 to 0.6.1.0.
- **The README lines follow the new version.** The Project README's skill claim follows. The system README's skill, changelog and release-notes lines and `SYNC.md` follow too.
- **The kernel stays at 0.7.0.** No kernel line changed.

No migration required.
