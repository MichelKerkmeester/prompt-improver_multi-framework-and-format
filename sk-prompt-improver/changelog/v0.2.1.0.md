# v0.2.1.0, One Brain and Extracted Mode Libraries

`SKILL.md` is now the single operating brain and the standalone system-prompt file is gone. The three largest mode references become slim workflow references plus mode library assets and `z_archive/knowledge base/` becomes `z_legacy/`. Every real skill reference and asset across all ten systems opens with a normalized overview.

## Why This Release

The frontmatter version in `SKILL.md` reads 0.2.1, up from the 0.1.0 the June 10 rollout shipped. No intermediate 0.2.0 commit exists in this folder's history. This entry documents the state actually on disk rather than an inferred stepping stone.

## What's New at a Glance

- **The standalone system prompt is deleted.** The file is `skill/references/system_prompt.md`. `SKILL.md` states that it is "the single operating brain" and that "no companion system-prompt file is required or allowed."
- **The three largest mode references slim down.** Example banks and quick-lookup material move from `image_mode.md` and `video_mode.md` into `assets/image_mode_library.md` and `assets/video_mode_library.md`. The framework matrix and selection algorithms move from `patterns_evaluation.md` into `assets/framework_pattern_library.md`.
- **Visual mode shrinks more modestly.** The release adds `assets/visual_mode_library.md` alongside `visual_mode.md`.
- **The format guides change path only.** `format_guide_json.md`, `format_guide_markdown.md` and `format_guide_yaml.md` move from `skill/references/` to `skill/assets/`. The content is otherwise unchanged.
- **The June 10 archive is renamed z_legacy.** The ten files under `z_archive/knowledge base/`, in the reference, system and templates folders, rename flat to `z_legacy/`. No file changes its content.
- **The knowledge mirrors move to new versions.** In `claude project/knowledge/`, Patterns and Evaluation moves from v0.201 to v0.210 and Visual Mode moves from v0.200 to v0.201. The three Format Guide mirrors move from v0.140 to v0.141.
- **Image Mode and Video Mode split into library mirrors.** In `claude project/knowledge/` they split into new "Assets - Image Mode Library" and "Assets - Video Mode Library" mirrors at v0.101.
- **References open with a normalized overview.** Every real skill reference and asset across all ten systems opens with `## 1. OVERVIEW`. Custom Instructions files get a prose pass that removes semicolons and em dashes.
- **The project docs follow the moved files.** `AGENTS.md`, `README.md` and `claude project/Custom Instructions.md` pick up that prose pass and the path updates for the moved files.

## Upgrade

Stop using `skill/references/system_prompt.md`. `SKILL.md` is the single operating brain and no companion system-prompt file is required or allowed. Read example banks and quick-lookup material from `assets/image_mode_library.md` and `assets/video_mode_library.md`. Read the framework matrix and selection algorithms from `assets/framework_pattern_library.md`. Use `assets/visual_mode_library.md` with the slimmer `visual_mode.md`. Read `format_guide_json.md`, `format_guide_markdown.md` and `format_guide_yaml.md` from `skill/assets/` instead of `skill/references/`. Open the ten archived files flat in `z_legacy/` rather than under `z_archive/knowledge base/` in the reference, system and templates folders.
