# v1.1.2.0, Visual Mode Grounds Its Subject First

This release reconciles Visual Mode (`$vibe`/`$v`) with an anti-default design canon. A brief must ground its subject before the VIBE framework runs. The EVOKE scoring gate rejects templated output no matter how evocative it reads.

## Why This Release

This is a scoring-surface change, the first since the June 15 flatten. It is not a packaging change.

## What's New at a Glance

- **Ground the Subject runs before VIBE.** The non-negotiable step covers Subject, Audience and Single Job.
- **Each brief carries a named avoidance list and one aesthetic risk.** The list covers a generic SaaS gradient, a centered hero plus three cards, an untouched component-library surface and three AI-default clusters. The brief also carries one justified aesthetic risk.
- **The EVOKE grounding pre-check scores a brief 0 if the brief lacks subject grounding or reads as a templated default.** This applies when the brief lacks subject grounding or reads as a templated default, even when the brief is evocative. The underlying 50-point dimension weights stay unchanged.
- **The eight design directions are category defaults.** They are reframed from a pick-one menu into defaults you name and then deliberately deviate from. Reusable across-briefs style presets are now prohibited.
- **A pre-output critique gate checks for a reusable brief.** It asks "would I produce this for any similar brief" and revises the brief if the answer is yes.
- **Patterns evaluation adds a seed-of-thought debias note.** `patterns_evaluation.md` and its mirror move from v0.210 to v0.211. The note applies for N of 2 or more variations.
- **The skill shows the new version.** `skill/SKILL.md` moves from version 1.1.1 to 1.1.2 to reflect the updated Visual Mode summary line.
- **The Visual Mode reference and its mirror carry the rewrite.** `skill/references/visual_mode.md` and the paired `Prompt Improver - Visual Mode - v0.300.md` mirror carry the bulk of the rewrite, with the mirror's version jumping from v0.201 to v0.300 to signal the redesign.
- **The README documents the same change.** `README.md` gains a new section titled "MAJOR UPDATE: Visual Mode Grounding-First Reconciliation" documenting the same list of changes for CLI readers.
- **The claude project files take version stamps.** `claude project/Custom Instructions.md` and `claude project/README.md` pick up matching version-stamp updates.
- **The visual mode library picks up an update in the same pass.** `assets/visual_mode_library.md` keeps its reusable UI vocabulary aligned with the grounding-first workflow.
