# Framework coverage brief

Twenty-four scenario pairs for Prompt Improver's manual testing playbook. Each pair tests that the system writes a Medium, High or Complex prompt that visibly uses one framework from its own library. The skill file carries the `SFW` ID and lives in `skill-framework-coverage/`; its Project twin carries the matching `PFW` ID and lives in `project-framework-coverage/`. Both files state the same Prompt, character for character, and have no conversation chain: the runner sends that one prompt and nothing more.

Every prompt carries its essentials, names its framework as a hint, carries one mode token and one explicit format token, and tells the runtime not to ask. Complex text prompts use `$deep`; Medium and High text prompts use `$improve`, or `$text` for RCAF and COSTAR, the two frameworks Text mode works in. `framework-brief.json` beside this file holds the same data for scripts.

Tier bands: Medium is complexity 5 to 6, High is 7 to 8 and Complex is 9 to 10.
